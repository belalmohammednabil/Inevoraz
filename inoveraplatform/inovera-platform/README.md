# INOVERA — نسخة حقيقية (Real Backend Edition)

نسخة معاد بناؤها من منصة INOVERA (School to Work)، بس بفرق جوهري: **البيانات هنا حقيقية**، متصلة بقاعدة بيانات فعلية (Supabase) بدل الأرقام الثابتة، ومضاف عليها **بوابة الشركاء** — الميزة اللي بتحول المنصة لمصدر دخل حقيقي (شركات بتدفع عشان توصل لطلاب جاهزين وتنشر فرص تدريب).

## إيه اللي شغال فعلياً هنا

- تسجيل دخول حقيقي (Supabase Auth) بـ5 أدوار: مدير نظام، مرشد طلابي، معلم، طالب، **شريك صناعي (شركة)**.
- صلاحيات حقيقية على مستوى قاعدة البيانات (Row Level Security) — مش مجرد إخفاء أزرار في الواجهة زي النسخة الأصلية.
- لوحة قيادة بتسحب أرقام حقيقية (عدد الطلاب، معدل الحضور، الجاهزية) من قاعدة البيانات.
- دليل طلاب، وسجل تدخلات قابل للإضافة والتعديل فعلياً.
- **بوابة الشركاء**: الشركة بتعمل حساب، تتصفح "قاعدة المواهب" (بيانات الطلاب مجهّلة الهوية)، تنشر فرص تدريب، وتتابع المتقدمين لحد التوظيف.
- طالب بيقدر يشوف فرص التدريب المتاحة ويقدّم عليها من حسابه.

## إيه اللي محتاج تعمله عشان يشتغل (حوالي 10 دقايق)

### 1) اعمل مشروع Supabase مجاني
روح على [supabase.com](https://supabase.com) → New Project (مجاني بالكامل).

### 2) شغّل ملف قاعدة البيانات
من داخل مشروعك في Supabase، افتح **SQL Editor** والصق فيه محتوى ملف
`supabase/migrations/0001_init.sql` كامل، واضغط Run. ده هيعمل كل الجداول والصلاحيات والبيانات التجريبية دفعة واحدة.

### 3) هات مفاتيح الاتصال
من **Project Settings → API**، انسخ:
- `Project URL`
- `anon public key`

### 4) حط المفاتيح في المشروع
انسخ ملف `.env.example` وسمّيه `.env`، واملأ فيه القيمتين.

```bash
cp .env.example .env
```

### 5) شغّل المشروع محلياً

```bash
npm install
npm run dev
```

هيفتح على `http://localhost:5173`.

## إزاي تجرب الأدوار المختلفة

من شاشة الدخول، اضغط "حساب جديد (تجربة)"، واختار الدور اللي عايز تجربه. لو اخترت "طالب"، الحساب هيتعمل بس مش هيتربط بطالب موجود تلقائياً (محتاج تربطه يدوياً من جدول `profiles` في Supabase بوضع `student_id` — دي نقطة تحسين مستقبلية سهلة).

لو اخترت "شريك صناعي (Company)"، هتقدر على طول تعمل ملف شركة وتبدأ تتصفح الطلاب وتنشر فرص.

## إزاي تنشره وتاخد رابط حقيقي (من غير حتى حساب)

1. اعمل نسخة إنتاج: `npm run build` (بيطلعلك فولدر `dist/`).
2. روح على [app.netlify.com/drop](https://app.netlify.com/drop) واسحب فولدر `dist` عليها — هتاخد رابط حقيقي فوراً من غير ما تعمل حساب.

للنشر الدائم باسمك ودومين خاص بيك، اربط المشروع بحساب [Vercel](https://vercel.com) أو [Netlify](https://netlify.com) (حساب مجاني) وحط نفس متغيرات `.env` في إعدادات المشروع هناك.

## هيكل المشروع

```
supabase/migrations/0001_init.sql   → قاعدة البيانات كاملة (جداول + صلاحيات + بيانات تجريبية)
src/lib/supabase.ts                 → الاتصال بـ Supabase
src/context/AuthContext.tsx         → إدارة تسجيل الدخول والدور
src/components/Layout.tsx           → القائمة الجانبية (تتغيّر حسب الدور)
src/pages/                          → كل شاشات النظام المدرسي
src/pages/partner/                  → بوابة الشركاء (الميزة التجارية الجديدة)
```

## حدود النسخة دي (بصراحة)

النسخة دي MVP حقيقي مش نظام كامل — أهم حاجة ناقصة: شاشة "إدخال البيانات" التفصيلية (حضور/سلوك/رفاه نفسي لكل طالب) مبنية بس مش موصولة بواجهة كاملة زي الأصلية، وشاشة "التقارير" والتصدير لسه محتاجة تتبنى. الأساس (قاعدة البيانات + الصلاحيات + بوابة الشركاء) هو الأهم وهو جاهز وشغال.
